What you get

Glyde is in an early preview. Each item shows whether it is in the build you can download or still being built.

In the preview

Private by default

No telemetry, no studies and no adverts. Strict tracking protection and secure connections are on from the first launch.

In the preview

Google search, built in

One search engine in the address bar. Suggestions are off, so nothing is sent while you type.

In the preview

Light on weak laptops

Fewer background processes, a smaller memory footprint and less disk activity, so older machines stay smooth.

In the preview

A calm start

A short setup guide, a gentle opening animation and a home page that tells you what is new.

In the preview

Update alerts

Glyde tells you when a new version is ready. The check runs once a day at most, and you can switch it off.

Being built

Getting started on Windows

  1. DownloadPick the Windows file above.
  2. UnzipRight click the file and choose Extract All.
  3. RunOpen the glyde folder and double click glyde.exe.

Good to know. Windows may show a blue "Windows protected your PC" box because Glyde is new and not yet signed. Choose More info, then Run anyway. If it says a file ending in .dll is missing, install the free Microsoft Visual C++ Redistributable (the X64 version) and try again.

Privacy in plain words

Glyde does not collect your browsing history or send usage reports. Searches go to Google, because that is the search engine built in, and Google's own privacy policy covers them. Read the full Privacy Policy.

Glyde is for people aged 13 and over. See Age and Young Users.
