Open Source and Trademarks

Last updated {{UPDATED}}

{{DRAFT}}

Glyde is built on Mozilla open source technology. It is not officially associated with Mozilla or its products.

1. What Glyde is built on

Glyde is based on the open source code behind Firefox, including the Gecko browser engine. It does not use Chromium. Mozilla publishes that code under the Mozilla Public License 2.0 and other licences.

2. How Glyde is licensed

  • Changes we make to Mozilla files stay under the Mozilla Public License 2.0, and we will publish them when Glyde is released to the public.
  • Other parts of the code are licensed as stated in the licence notices that ship with the program.
  • The Glyde name, logo and website design are not covered by those licences. You may not use them without our written permission. If you make your own version of Glyde, it needs its own name and logo.

3. The Szimon Engine

The Szimon Engine and Szimon assistant are separate from the browser and are not open source at this time. We may release them in future, and will say so here if we do.

4. Trademarks

  • Firefox and Mozilla are trademarks of the Mozilla Foundation in the United States and other countries.
  • Google is a trademark of Google LLC. Glyde uses Google Search as its built-in search engine and is not affiliated with or endorsed by Google.
  • All other names belong to their owners.

Glyde does not use Mozilla's logos or names as its own branding. We say in words that Glyde is built on Mozilla technology because it is true, and because the people who made that technology deserve credit.

5. Other open source software

Glyde and this website may use other open source software. A full list of components and their licences will ship with each release in the program's licence notices.
