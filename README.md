# Glyde

A private browser built on Mozilla's open source Firefox code (the Gecko engine). Own name, own logo, Google as the only search engine, no telemetry, and a focus on customisation and privacy.

Built on Mozilla open source technology. Not officially associated with Mozilla or its products.

## Repository layout

| Folder | What it is |
| --- | --- |
| `browser/` | The Firefox fork: pinned version, branding generator, privacy defaults, policies, build scripts |
| `site/` | The public website: download page and all legal documents |
| `pwa/` | The earlier web app. Kept as the companion for iPhone and iPad, where no other engine is allowed |
| `docs/` | Roadmap, build guide and the list of network connections |
| `.github/workflows/` | Build automation |

Start with [`docs/ROADMAP.md`](docs/ROADMAP.md) and [`docs/BUILDING.md`](docs/BUILDING.md).

## Status

Early development. No public download exists yet. The first build pipeline is written but has not been run.
